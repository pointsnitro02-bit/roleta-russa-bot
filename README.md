# Bot de Discord - Roleta Russa

Um bot de Discord para jogar roleta russa com até 6 jogadores. 

## Comandos

- `!roletarussa <balas> <jogadores>`: Inicia um jogo de roleta russa. 
- Jogadores que levam uma "bala" serão mutados por 10 minutos.

## Configuração

- Configure o bot no [Discord Developer Portal](https://discord.com/developers/applications).
- Use o Railway para deply. Adicione a variável de ambiente `DISCORD_BOT_TOKEN` com o token do seu bot.
