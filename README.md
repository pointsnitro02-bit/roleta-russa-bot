# Bot de Discord - Roleta Russa

Um bot de Discord para jogar roleta russa com até 6 jogadores.

## Comandos

- `/roletarussa <balas> <jogadores>`: Inicia um jogo de roleta russa com interação de botão.

## Configuração

- Configure o bot no [Discord Developer Portal](https://discord.com/developers/applications).
- Certifique-se de habilitar as intenções privilegiadas necessárias para o bot trabalhar.
